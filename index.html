NLP Based Drift Detection

Concept Project

Engineered an NLP system to detect "Concept Drift" by quantifying semantic shifts between 2023 historical baselines and current news headlines. Developed a mathematical drift score (I - cosine similarity) using TF-IDF Vectorization to monitor how news topics evolve over time. Architected a FastAPI backend to handle high-concurrency requests, serving serialized model artifacts (.pkl) for efficient, low-latency inference. Dockerized the entire environment to ensure cross-platform reproducibility and deployed the containerized application on Render with a live Streamlit frontend.
